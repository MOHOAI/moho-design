تصميم موهو
Moho Design

تنسيق مفتوح لملفات .mo ومحوّل TypeScript/JavaScript لبناء أنظمة تصميم موحّدة، قابلة للنقل، متاحة الوصول، وداعمة للاتجاه RTL. اكتب مصدر التصميم مرة واحدة، ثم حوّله إلى CSS أو JSON أو استخدمه من API مباشرة.

التثبيت من npm استعراض GitHub فتح مثال .mo

ما هو Moho Design؟

ملف .mo هو مصدر تصميم آمن قابل للتحقق، وليس ملفًا تنفيذيًا. يصف الألوان والمسافات والطباعة والمكوّنات والحالات والاتجاه وإرشادات الوصول، بينما يتولى المترجم إنتاج مخرجات مناسبة لتطبيقات الويب.

مصدر واحد

اجمع design tokens والمكوّنات والتكاملات الوصفية في نموذج MO منظم.

إخراج عملي

حوّل الملف إلى CSS variables أو JSON، أو استورده من JavaScript وTypeScript.

RTL و الوصول

صمّم للعربية واللغات ثنائية الاتجاه مع حالات وصول موثقة.

نواة صغيرة

لا تثبّت النواة مئات المكتبات؛ توفر adapters اختيارية وكتالوجًا وصفيًا.

بدء سريع

npm install moho-design

import { parseMo, compileMoToCss } from "moho-design";

const source = await fetch("/design/moho-default.mo").then((r) => r.text());
const design = parseMo(source);
const css = compileMoToCss(design);

الوثائق والمصادر

يمكنك قراءة المواصفة، مراجعة سجل التغييرات، فحص الكتالوج المجاني، أو فتح مشكلة في المستودع. تظل رخصة كل تكامل خارجي منفصلة، ولا يعني ظهوره في الكتالوج أن كوده أُعيد توزيعه داخل الحزمة.
