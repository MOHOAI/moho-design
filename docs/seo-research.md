
# بحث قابلية الاكتشاف — 2026-08-14

## نتائج المصادر الرسمية

1. توضح Google Search Central أن JSON-LD والبيانات المنظمة تساعد Google على فهم محتوى الصفحة، لكنها لا تضمن ظهورًا غنيًا أو ترتيبًا محددًا. يجب أن تصف البيانات المنظمة محتوى ظاهرًا وحقيقيًا، وأن تُراجع عبر Rich Results Test.
2. توضح Google أن sitemap يساعد محركات البحث على اكتشاف الصفحات، خصوصًا للمواقع الجديدة أو التي تملك روابط خارجية قليلة؛ لكنه ليس بديلًا عن الربط الداخلي الجيد.
3. توصي npm بوجود README.md في جذر الحزمة لأن npm يعرضه في صفحة الحزمة، ولا يتحدث README المعروض على npm إلا عند نشر إصدار جديد.

## تطبيقات مقترحة على MOHO

سيُحسّن المشروع عنوان ووصف README، الكلمات المفتاحية الطبيعية، أمثلة الاستخدام، روابط GitHub وnpm، وصف الحزمة وkeywords، وملفات وثائق HTML قابلة للفهرسة. ستُستخدم JSON-LD فقط في صفحات الوثائق التي تعرض المحتوى نفسه، مع sitemap وروابط داخلية. لا يجوز استخدام schema أو كلمات مفتاحية مخفية أو ادعاءات مثل «أفضل مكتبة» دون دليل.
